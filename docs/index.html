Spotify Widget for Corsair Xeneon Edge

About Privacy & Security

To control Spotify from your Xeneon Edge, the widget needs permission to read your playback status and control playback (play, pause, skip, volume). This is done through Spotify's official OAuth authorization process.

We never see or store your data. The authorization happens entirely in your browser between you and Spotify. The generated Client ID and Refresh Token are only stored locally in your browser during setup and in your iCUE widget settings afterward. Neither this page nor the widget sends data anywhere except to Spotify's official API.

Keep your Client ID and Refresh Token private. While a Refresh Token is less sensitive than a Client Secret, it should still be treated like a password. Anyone with both values could control your Spotify playback.

  • Authorization happens entirely in your browser
  • No data is sent to any server except Spotify's official API
  • Tokens are stored locally in your browser and iCUE settings
  • No companion server or cloud service required
